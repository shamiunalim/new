# Maxiel Floating
Proyek Android native untuk kontrol bulat mengambang di atas aplikasi lain.

Buka di Android Studio lalu Build > Build APK(s).
Berikan izin "Tampil di atas aplikasi lain". Overlay memakai foreground service sehingga dapat tetap aktif ketika berpindah aplikasi.

Fitur SS dan REKAM LAYAR pada template menampilkan pemberitahuan bahwa Android membutuhkan persetujuan MediaProjection. Tidak ada bypass izin, DRM, atau perekaman diam-diam.
