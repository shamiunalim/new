Nama & Ikon Aplikasi

MAXIEL
PREVIEW Maxiel Siap dipasang sebagai aplikasi
Hasil pemasangan: Maxiel akan muncul sebagai ikon di layar utama HP. Saat ikon itu ditekan, website Maxiel terbuka seperti aplikasi dan tidak perlu mengetik alamat lagi.

Jika tombol tidak membuka dialog otomatis, gunakan Chrome ⋮ → Tambahkan ke layar utama / Instal aplikasi.
Catatan: ini adalah PWA (web app), bukan file APK. Ikon/nama yang sudah terpasang dikelola Android/Chrome dan tidak dapat dipaksa berubah hanya dari JavaScript website.

Nama dan foto ikon di halaman ini tersimpan di perangkat. Favicon dan tampilan website mengikuti pengaturan. Untuk ikon/nama launcher PWA yang benar-benar berubah setelah instalasi, manifest dan file ikon harus diperbarui di server lalu PWA dipasang ulang.
