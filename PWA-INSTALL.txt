MAXIEL - PASANG SEBAGAI APLIKASI DI HP

1. Buka website melalui HTTPS.
2. Buka Settings > Nama & Ikon Aplikasi.
3. Simpan nama/ikon yang diinginkan.
4. Tekan PASANG KE HP.
5. Jika Chrome tidak menampilkan dialog otomatis, tekan menu ⋮ > Tambahkan ke layar utama / Instal aplikasi.
6. Setelah selesai, ikon Maxiel muncul di layar utama. Menekan ikon membuka website Maxiel dalam mode aplikasi.

PENTING
Ini adalah PWA (Progressive Web App), bukan APK Android native. Nama/ikon launcher yang sudah terpasang tidak bisa diubah secara paksa dari JavaScript halaman. Untuk mengubah metadata launcher PWA, manifest.json dan ikon yang dipublikasikan di server harus berubah, kemudian PWA perlu dipasang ulang.
